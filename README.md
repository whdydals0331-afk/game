# 딱맞음

들어갈 듯 말 듯… 그러다 **딱.** 손끝으로 긴장했다가 한 번에 풀리는 느낌을 모은 작은 웹 게임 모음.
설치·빌드 없이 `index.html` 을 열면 바로 된다. 소리는 Web Audio 로 직접 만들고, 안드로이드에서는 진동도 쓴다.

| 게임 | 하는 것 | 긴장 → 딱 |
|---|---|---|
| 틈새 밀기 | 조각을 나무 홈에 밀어 넣기 | 표면에서 살살 조준, 어긋나면 턱. 맞으면 뻑뻑하게 찔끔찔끔 → 빡빡한 구간 → 빨려 들어가며 쿵 |
| 빙글 쏙 | 돌고 있는 조각을 톡 떨어뜨리기 | 살짝 어긋나면 모서리에 걸려 버티다 드르륵 돌아 쑥 |
| 책꽂이 | 빈틈에 맞는 책 골라 꽂기 | 두꺼우면 퉁 튕기고, 얇으면 헐렁. 맞는 책은 양옆을 밀어내며 쑤욱 |
| 딸깍 꽂기 | USB-C·USB-A·전원·랜선·이어폰 | 반대 방향이면 툭. 맞으면 빡빡하다가 딸깍, 불이 켜짐 |
| 꾹 딸깍 | 밀폐용기 날개 잠그기 / 잼 병 돌려 잠그기 | 꾹 누르면 버티다가 딸깍 / 끝에서 뻑뻑해지다 뽁 |
| 싹싹 청소 | 청소기 헤드로 카펫 밀기 | 가구 사이 틈에 헤드가 쏙, 카펫 결이 줄무늬로 |
| 빈칸 채우기 | 블럭 조각을 빈자리에 | 가볍게 쉬어 가는 판 |

## 구조

- `js/core.js` — 소리, 진동, 캔버스 무대, 효과, 그리고 모든 게임이 같이 쓰는 "뻑뻑함" 물리
  - `Press`: 손가락이 물체보다 앞서 나간 만큼 힘이 쌓이고, 문턱을 넘으면 찔끔 미끄러진다(stick-slip). `profile(p)` 로 구간별 빡빡함을 정하고, `snapAt` 을 넘으면 남은 거리를 한 번에 빨려 들어간다(슬로모션 + 쿵)
  - `Inserter`: 입구에 닿으면 표면 위를 천천히 미끄러지며 조준, 어긋나면 걸림, 맞으면 Press 로 삽입
- `js/g-*.js` — 게임 하나당 파일 하나. `DDAK.register({...})` 로 등록
