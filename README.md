# 딱맞음

마음이 편해지는 작은 웹 게임. 파일 하나(`index.html`)로 돌아가고, 설치·빌드가 필요 없다.

- **블럭 끼우기** — 조각을 끌어서 빈자리에 놓는다. 모양이 정확히 같은 자리에만 "딱" 들어간다. 단계가 오를수록 판이 커지고 조각이 많아진다.
- **싹싹 청소** — 화면을 끌면 청소기 헤드가 따라온다. 지나간 자리는 먼지가 사라지고 카펫 결이 남는다(위로 밀면 밝게, 아래로 당기면 진하게). 가구 사이 틈은 헤드보다 4px 넓어서 헤드가 쏙 들어가고, 들어갈 때 소리와 진동이 난다. 방 5개.

소리는 Web Audio로 직접 만들고, 폰에서는 진동도 쓴다. 진행 단계는 그 브라우저에만 저장된다.

## 실행

`index.html` 을 브라우저로 열면 된다. 폰에서 보려면 GitHub Pages 를 켜면 된다 (Settings → Pages → main 브랜치).
